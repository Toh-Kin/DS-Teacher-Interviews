# Interview Recorder v0.1 セットアップ手順（Kin用）

## 全体像（3つの部品）
1. **アプリ**（`app/` フォルダ）… スマホで開く録音・メモ画面。ネットに置く（無料）。
2. **受信窓口**（`gas/Code.gs`）… Googleスプレッドシートに貼り付けて動かす。質問を配り、録音とメモを受け取る。
3. **スプレッドシート＋Drive** … 質問・学校リストの入力場所、結果の保存場所。

## 手順1: スプレッドシートと受信窓口（所要 約10分）
1. Googleスプレッドシートを新規作成し、名前を「DS Teacher Interviews」などにする。
2. メニュー **拡張機能 → Apps Script** を開く。
3. 最初からあるコードを全部消し、`gas/Code.gs` の中身を貼り付ける。
4. 上の方の `const PASSCODE = 'CHANGE-ME';` の `CHANGE-ME` を、チームだけの合言葉に変える（英数字）。保存（💾）。
5. 上部の関数選択で **setup** を選び「実行」。初回は権限の承認が出る
   （「詳細」→「（安全でないページ）に移動」→ 許可）。
   → スプレッドシートに 5枚のシート（Questions / Schools / Interviewers / Interviews / Notes）ができ、
   Driveに「DS Teacher Interviews」フォルダができる。
6. **デプロイ → 新しいデプロイ → 種類「ウェブアプリ」**
   - 次のユーザーとして実行: **自分**
   - アクセスできるユーザー: **全員**（合言葉で守られます）
   → 表示される **ウェブアプリのURL（…/exec）** をコピー。ブラウザで開いて
   「Interview Recorder server is running」と出ればOK。

> コード（Code.gs）を後で変更したときは「デプロイ → デプロイを管理 → 編集 → 新バージョン」で更新が必要です。
> 録音の保存先Driveフォルダを後で指定するときは、フォルダURLの末尾のIDを `FOLDER_ID` に入れて同じ手順で更新します。

## 手順2: アプリをネットに置く（無料）
`app/` の中の6ファイル（index.html, sw.js, manifest.webmanifest, 画像3枚）を、**フォルダ構成を変えずに**置く。
- **A. GitHub Pages**: 公開リポジトリを作り、6ファイルをアップロード → Settings → Pages → Branch: main / root。
  URLは `https://（ユーザー名）.github.io/（リポジトリ名）/`。
- **B. Netlify Drop**（簡単）: netlify.com/drop に `app` フォルダをドラッグ。すぐURLが出る。

アプリのファイルに合言葉やURLは入っていないので、公開して問題ありません（合言葉はスマホ側に入力します）。
必ず **https** のURLを使ってください（マイクと、オフライン動作に必要）。

## 手順3: 自分のスマホで設定
1. アプリのURLを開く（iPhoneは **Safari**、Androidは **Chrome**）。
2. **Settings** に手順1のURLと合言葉、自分の名前を入力 → **Save and update questions**。
   「Done. 6 questions…」と出れば成功。
3. **ホーム画面に追加**（Android: メニュー → アプリをインストール / iPhone: 共有ボタン → ホーム画面に追加）。
   通信がある場所で、**ホーム画面のアイコンから一度開いておく**（オフライン用にアプリが端末に入ります）。

## 手順4: 現地チーム2名に配る
Settings の **Copy setup link for teammates** でリンクを作り、個別に（WhatsApp等で）送る。
リンクを開くと、URLと合言葉が自動で入る。あとは手順3の2〜3と同じ。

## 質問を入れる（明日）
スプレッドシートの **Questions** シートに、1行1質問で書く。

| 列 | 内容 |
|---|---|
| No | 質問番号 |
| Section | 見出し（例: A. Observation） |
| Stage | 小さなタグ（Observation / Feedback / Advice / Re-observation など）。突合の軸にもなる |
| Question | 質問文（英語） |
| Probe | 深掘りの聞き方（任意） |
| Required | Y なら必須、空欄は任意 |

学校名は **Schools**、聞き手は **Interviewers** シートの1列目に縦に書く。
**反映のしかた**: 各スマホで Wi-Fi がある場所で Settings → **Save and update questions**。
（更新前に録音したインタビューには、そのときの質問文が記録されるので、あとで質問を直しても混ざりません。）

## 結果の見え方
- **Interviews** シート: 1インタビュー1行（日付・学校・ID・聞き手・時間・録音ファイルのリンク・全体所感）。
- **Notes** シート: 1質問1行（質問文・**録音内でその質問を始めた時刻**・メモ・⚑マークの時刻）。
- Drive: `20261118_学校名_ID.webm`（iPhoneは `.m4a`）。

## 来週の前にやるテスト（重要）
このアプリは、Googleの代わりに作った模擬環境と、実際のChromeでは動作確認済みですが、**本物のGoogle（Apps Script/Drive）とiPhoneでの確認はまだ**です。次を必ず試してください。
1. 自分のスマホで、通常の送信（Wi-Fi）→ スプレッドシートとDriveに入るか。
2. **機内モード**で録音 → 保存 → Wi-Fiに戻して送信。
3. **30分以上**の連続録音（途中で画面を消さない）。iPhoneは画面をロックすると録音が止まることがあります。
4. iPhoneとAndroidの両方で。

## 運用の注意
- **画面は点けたまま**。録音中にアプリを切り替えない。
- **その日のうちに送信**（特にiPhone。ブラウザの保存データは消えることがある）。
- Driveで録音を確認するまで、スマホからは削除しない。
- 録音ボタンを押す前に、同意の確認が必要（チェック欄あり）。
- IDはイニシャルのみ。録音は個人情報なので、Driveの共有範囲は必要な人だけに。
